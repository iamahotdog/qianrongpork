千容肉品 v42.1｜舊 Google Sheet 欄位自動遷移

本版目的：
讓目前舊版 Sheet 表頭可安全轉換為正式後臺欄位，不再因欄位名稱不符而拒絕寫入新訂單。

目前舊表頭支援：
訂單編號、建立時間、姓名、電話、宅配方式、收件人、地址、訂單細項、
總數量、商品明細、總包數、總金額、匯款後五碼、備註、請求識別碼、
訂單狀態、付款狀態、出貨狀態、收件人電話

遷移後正式表頭：
訂單編號、建立時間、訂購人姓名、訂購人電話、收件人姓名、收件人電話、
配送方式、收件地址、訂單細項、總包數、商品金額、運費、應付總額、
匯款後五碼、訂單狀態、付款狀態、出貨狀態、備註、請求識別碼

舊資料對應：
- 姓名 → 訂購人姓名
- 電話 → 訂購人電話
- 收件人 → 收件人姓名
- 收件人電話 → 收件人電話
- 宅配方式 → 配送方式
- 地址 → 收件地址
- 總數量 → 總包數
- 商品明細 → 商品金額
- 舊「總包數」→ 運費
- 總金額 → 應付總額

使用方式：
1. 先複製 Google Sheet 做備份。
2. Apps Script 貼入 v42.1 程式碼並儲存。
3. 可先執行 previewMigrationV421()：
   - 只顯示判讀結果，不修改 Sheet。
4. 確認後執行 migrateSheetLayoutV421()：
   - 會搬移舊資料
   - 重建 19 個正式欄位
   - 刪除右側多餘空白欄
   - 凍結表頭
   - 設定欄寬
   - 建立篩選器
5. 回 Google Sheet 確認舊訂單資料正確。
6. 確認後再：
   部署 → 管理部署作業 → 編輯目前正式 deployment → 新版本 → 部署
7. 更新 GitHub Pages index.html。

補充：
V42.1 的 ensureHeaders_ 也會在偵測到舊版欄位時自動執行 migration，
但仍建議第一次先手動執行並確認資料。
