千容肉品 v43.1｜商品最後更新時間自動化

本次調整：
1. 「商品管理」工作表的「最後更新」改為真正的單列修改時間。
2. 只有修改以下欄位時，才會自動更新該商品這一列的「最後更新」：
   - 售價
   - 庫存
   - 是否販售
   - 單次上限
3. 修改其他商品不會影響未修改商品的最後更新時間。
4. 修改商品名稱不會自動更新最後更新時間。
5. 更新時間固定使用 Asia/Taipei：
   yyyy/MM/dd HH:mm:ss
6. 商品資料有變動時，同時清除商品主檔 Cache，
   下一次前端讀取即可取得新的設定。
7. 移除舊版「一次刷新全部商品時間」的手動邏輯。

範例：
若只修改「里肌肉」售價：
里肌肉｜220｜30｜TRUE｜20｜2026/08/10 14:42:35

其他商品的最後更新時間保持不變。

注意：
Apps Script 的 simple trigger `onEdit(e)` 只有在使用者直接編輯 Google Sheet 時觸發。
系統自動扣庫存屬於 Apps Script 程式寫入，不會觸發 onEdit。
這樣可以避免「客人下單扣庫存」被誤認為管理者修改商品設定。

部署：
1. Apps Script 貼入 v43.1。
2. 儲存。
3. 部署 → 管理部署作業 → 編輯正式 deployment → 新版本 → 部署。
4. GitHub Pages 的 index.html 也更新為 v43.1。
5. health check 應回傳 version: v43.1。
