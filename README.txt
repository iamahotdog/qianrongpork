千容肉品訂購 Web App v41.9｜送單加速與 LINE 格式恢復

本次調整：
1. 移除 LINE 訂單中的：
   「訂單資料已送出，正式金額請以千容肉品確認為準。」
2. 恢復之前定稿的 LINE 訂單格式：
   【千容肉品訂單】
   訂單編號：QR...
   商品
   ・品名 ×數量
   應付總額：$...
   配送方式：...
   匯款後五碼：.....
3. 送單流程改為非阻塞：
   - 按下送出後立即進入成功頁。
   - 不等待 Google Apps Script / Google Sheet 完成才切頁。
   - POST 與後端驗價改在背景處理。
4. 成功頁立即顯示訂單編號。
5. 後端確認完成後才啟用「複製訂單內容」，避免使用前端可能被竄改的金額。
6. 背景確認改為 POST 完成後立即查詢，必要時再短暫重試：
   0 秒、0.6 秒、1.4 秒、2.6 秒。
7. 不再產生「已送出」或「正式金額請以...」等替代訂單內容。
8. Google Apps Script 沿用 v41.8，本版不需要修改後端。

部署：
- GitHub Pages 更新 index.html 即可。
